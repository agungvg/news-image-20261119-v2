THE WORLD — a newspaper front page that sums up Thursday 19 November 2026's world news in one image. The Trump–Xi–Putin trilateral in Shenzhen leads, with 35 stories from 7 regions and a day-in-numbers box, drawn from scratch with Pillow.

## Run it

```sh
python3 draw.py
```

That writes `entry.png` (1024×1024, deterministic — two runs write byte-identical PNGs). `python3 main.py` writes the same image to `/output/entry.png` instead. No network, no clock, no randomness.
